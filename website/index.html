C — PRIVACY

Windows privacy signals.
No camera or mic capture.

Pulse reads Windows camera and microphone use status to show an indicator. It does not capture audio or video. Notification previews and clipboard text previews are opt-in.

OPTIONAL BROWSER BRIDGE

Bring browser activity
into Pulse.

Use the extension for download progress and websites that create native browser notifications.

01 / INSTALL

Add the extension

Download and extract the ZIP. In Chrome open chrome://extensions, or in Edge open edge://extensions. Turn on Developer mode, choose Load unpacked, and select the extracted folder that contains manifest.json.

Download extension ZIP ↓
02 / PERMISSIONS

Allow site notifications

For Discord Web, open discord.com, use the site controls beside the address bar, and set Notifications to Allow. In Discord, keep the relevant server and channel notifications enabled.

Pulse receives only notifications the page sends through the browser Notification API. It does not read Discord chats, unread badges, or Discord’s desktop app.

03 / TRY IT

See the bridge work

Keep Pulse and the browser extension running. When a supported website raises a browser notification, Pulse can show its title and body. Start a browser download to see its filename and progress.

The extension is an unpacked source package, not a Chrome Web Store listing. It requests access on all sites to observe notification API calls, plus browser download access.

Manage site notification permissions in Chrome Settings → Privacy and security → Site settings → Notifications. Discord’s server notification controls are described in its notification settings guide.
