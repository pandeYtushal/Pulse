PRIVACY NOTES

What Pulse reads
and where it goes.

Pulse processes Windows activity locally so it can show temporary status. It has no analytics or remote API integration.

Windows activity

Pulse reads current media metadata and playback state, Windows notifications (with OS permission), battery/power events, camera and microphone use state, USB/Bluetooth connection events, screenshot filename events, and clipboard change information. It does not capture audio, video, or screenshot image contents.

Notifications

Notification text stays in process memory while displayed or deduplicated. It is not written to Pulse settings or notification history. Previews are off by default. A built-in sensitive-app list hides message bodies. The optional media diagnostic command can write the current player title, artist, status, and timeline to the console; review and redact output before sharing.

Clipboard

Clipboard changes can be shown as temporary activity. Sanitized text previews are opt-in. Pulse does not keep clipboard history. Preview data stays in memory for the duration of the activity.

Downloads and browser notifications

The optional, unpublished browser extension has broad page access because it observes page calls to the browser Notification API. It forwards web notification title/body and the page hostname to Pulse over the local loopback bridge. Download events include a file basename and progress metadata. This information is sent to the Pulse process on the same device, not to a remote Pulse server. The local bridge does not authenticate other local processes.

Settings and diagnostics

Pulse settings and onboarding completion are persisted by the WebView in local storage. Activity content is not stored there. Pulse has no configured telemetry, crash-report upload, or diagnostic upload service. Local console output may include media metadata when the explicit diagnostic command is used.

Public release status

The source repository, public installer, and Chrome Web Store listing are not configured yet. The extension source in the repository is optional and is not published in a store.
